## 🚀 Getting Started

### Prerequisites
- Adobe After Effects (2022 or later recommended)
- 4GB+ RAM
- GPU acceleration enabled

### How to Use

1. **Clone or Download** this repository
   ```bash
   git clone https://github.com/unoduxx75-a11y/after-effect-ui-customizer.git
   ```

2. **Open in After Effects**
   - Launch Adobe After Effects
   - File → Open → Select the `.aep` project file

3. **Customize**
   - Edit text, colors, and animations
   - Adjust timing and effects as needed
   - Preview in real-time

4. **Export**
   - Composition → Add to Render Queue
   - Choose output format (MP4, MOV, PNG Sequence)
   - Render and save

## 🎨 Customization Tips

### Colors & Branding
- Edit solid color layers in Effect Controls
- Adjust color grading in the Color Correction layer
- Modify text color in Text properties

### Animation Speed
- Select composition
- Change frame rate or duration
- Adjust keyframe timing

### Audio
- Add audio files to the Audio layer
- Sync animations with music beats
- Use audio visualization effects
